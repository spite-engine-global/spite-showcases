# Asset licences and provenance

The owner has confirmed that the assets in the release are cleared for redistribution. The code's MIT licence does not automatically apply to these assets; their source terms apply.

- **Warzone:** vehicle, building, terrain, texture, effects and sound sets, plus the GIGA Chad and truth nuke models. The supplied source project does not identify a separate upstream author or licence for each of these groups.
- **City:** procedural buildings, roads, vehicles, textures and people. City textures derive from [ambientCG](https://ambientcg.com/) assets (CC0). The Microsoft Rocketbox people are MIT licensed; see [Rocketbox licence](licenses/Rocketbox-LICENSE.md).
- **Formations and UI Storm:** the formations geometry and UI data supplied with the source projects. The installed SDK provides engine fonts and styles separately.
